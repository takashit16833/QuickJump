# Support

QuickJump uses GitHub Issues for bug reports and feature requests:

https://github.com/takashit16833/QuickJump/issues

## Bug reports

When possible, include:

- QuickJump version;
- VS Code version;
- operating system;
- whether VSCodeVim or another modal editing extension is enabled;
- relevant `quickJump.*` settings;
- steps to reproduce the problem;
- what you expected to happen and what happened instead.

A minimal reproduction is especially helpful for problems involving split editor groups, folding, Sticky Scroll, or custom keybindings.

## Feature requests

Please describe the workflow you want to improve rather than only the implementation you have in mind. QuickJump is intentionally focused on fast jumps to visible text, so additions should preserve that small scope.
